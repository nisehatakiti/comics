# にゃかきち — Canonical Assets

このディレクトリは、にゃかきちの漫画制作における正典キャラクター資料を管理する。

## Canonical Design

正典設定は [`character.md`](./character.md) を参照する。

## Canonical Image

正典キャラクターシートは次のファイル名で管理する。

`design/character-sheet.jpg`

この画像は、正面・側面・背面、表情、基本ポーズ、カラー、首輪などを確認するための基準資料とする。

## Fixed Visual Features

- キジ白（グレー系キジトラ＋白）
- 大きな黄緑〜金色の目
- 白い口元・胸
- 長い縞模様の尻尾
- **ピンクの首輪**
- **小さな金色の肉球型チャーム**

衣装やポーズはエピソードごとに変えてよいが、上記の固定要素は原則として変更しない。
