# にゃかきち — Canonical Character Definition

## Overview

にゃかきちは、時事・社会テーマを扱う学習漫画シリーズの主人公。読者と同じ目線で「なぜ？」「どういうこと？」と疑問を持ち、取材・観察・体験・調査を通じて理解を深めていく案内役。

このファイルは漫画制作における**正典（Canonical）キャラクター設定**とする。

## Visual Identity — MUST NOT CHANGE

- Species: 猫（雑種・キジ白 / グレー系キジトラ＋白）
- Gender: オス
- Approximate age: 推定3歳程度
- Style: 二足歩行の擬人化猫。親しみやすい児童・一般向け漫画表現。写実的すぎず、極端なデフォルメにも寄せない。
- Body: 丸みのある体型、やや大きめの頭、漫画として動かしやすい四肢。
- Face: 丸みのある猫顔、柔らかな輪郭、小さなピンク色の鼻、白い口元、長めの白いヒゲ。
- Eyes: 大きめのアーモンド形。黄緑〜金色系。猫らしい縦長の黒目。表情豊か。
- Ears: 三角形の猫耳。外側はキジ柄、内側は淡いピンク。
- Fur: グレー系のキジトラ。額・頭頂・顔に濃い縞模様。口元・胸・腹部は白。前脚・後脚にも白い部分を持つ。
- Tail: 長めで標準的な太さ。グレー地に濃い縞模様、先端は濃色。
- Paw pads: ピンク。

## Collar — MUST NOT CHANGE

にゃかきちは**必ずピンク色の首輪**を着用する。

- Color: やわらかなピンク
- Width: 細め〜標準
- Material impression: シンプルな革または布
- Decoration: **小さな金色の肉球型チャーム**を首輪中央付近から下げる
- The pink collar + gold paw charm are signature identifying features.

### Prohibited default substitutions

通常デザインでは以下に置き換えない。

- スカーフ
- バンダナ
- ネクタイ
- マフラー
- 大きなリボン
- 別色の首輪
- 派手な首飾り

衣装が必要なエピソードでは追加衣装を着せてもよいが、可能な限りピンクの首輪と金色の肉球チャームを維持する。

## Clothing

通常時は服を着ない。必要に応じて学校・取材・季節・時代設定に合わせた衣装を追加してよい。

衣装変更後も、顔、毛色、模様、目、耳、尻尾、ピンクの首輪を基本的に維持する。

## Personality

- 好奇心旺盛
- のんびりしている
- 素直
- 少しおっちょこちょい
- 人の話を聞くのが好き
- 新しいことを知るのが好き
- 分からないことを恥ずかしがらない
- ときどき勘違いする
- 失敗しても前向き

Core trait: **「分からないことを、そのままにしない」**

## Role in Educational Current-Affairs Manga

にゃかきちは先生ではなく、**読者と同じ立場の案内役**。

基本フロー:

1. ニュースや身近な現象に出会う
2. 疑問を持つ
3. 調べる
4. 専門家・当事者などに話を聞く
5. 現場を見る
6. 複数の立場や背景を知る
7. 読者と一緒に考える

最初から正解を知っているキャラクターにはしない。

## Speech

- First person: 「ぼく」
- Basic sentence ending: 「〜にゃ」
- 「にゃ」をすべての台詞に機械的に付けず、自然な会話を優先。

Typical phrases:

- 「それ、どういうことにゃ？」
- 「なんでそうなるのにゃ？」
- 「知らなかったにゃ！」
- 「ちょっと調べてみるにゃ。」
- 「なるほど、そういうことかにゃ。」
- 「でも、それだけじゃないみたいにゃ。」
- 「いろんな人に聞いてみるにゃ。」

## Allowed Variation

以下は場面に応じて変化してよい。

- 表情
- ポーズ
- 尻尾の動き
- 耳の角度
- 一時的な汚れ・濡れ・泥
- 衣装
- 小物
- 背景
- 漫画的なデフォルメ度

## Design Recognition Priority

作画情報が多くなった場合、次の順で一貫性を優先する。

1. キジ白の毛色・模様
2. 黄緑〜金色の大きな目
3. 白い口元・胸
4. ピンクの首輪
5. 金色の肉球チャーム
6. 猫耳・猫顔
7. 長い縞模様の尻尾
8. 丸みのある体型

## Canonical Prompt

二足歩行のキジ白猫、丸みのある親しみやすい体型、大きな黄緑〜金色の目、白い胸と口元、額と顔にキジトラ模様、長い縞模様の尻尾、**ピンクの首輪**、**小さな金色の肉球チャーム**、表情豊か、児童向け・一般向け学習漫画の主人公、柔らかな漫画表現。
